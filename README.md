### Sobre mí

Construyo aplicaciones web que usan negocios reales, y me encargo de todo el ciclo: hablar con el cliente, modelar la base de datos, programar frontend y backend, y dejarlo funcionando en producción.

Hice mi práctica en **ciberseguridad en Accenture**, donde aprendí a pensar el software como lo haría un atacante. Eso lo aplico en cada proyecto: validar lo que llega de afuera, proteger los datos y no exponer errores internos.

- Hoy tengo dos aplicaciones en producción usadas por clientes reales.
- Estoy aprendiendo **testing** y **arquitecturas escalables**.
- Busco un equipo como **Desarrollador Full Stack** o **Frontend** donde aportar desde el primer día.

### Casos reales

El código de estos proyectos es privado porque maneja datos de clientes. En cada caso de estudio cuento el problema, lo que decidí, lo que falló y cómo lo resolví.

#### Hair Day · Reservas para salón de belleza
Las clientas reservan servicio, día y hora sin escribir por WhatsApp, y la estilista administra todo desde un panel. En uso real desde mediados de 2026.

**Stack:** React · Node.js · Express · PostgreSQL · Vercel · Railway
**[Ver en vivo](https://reservapelu.com/)** · **[Caso de estudio](https://github.com/EdinsonR7/hairdaycase-study)**

#### SebMay · Marketplace para negocios locales
Marketplace de dos lados con suscripción para vendedores y pagos con Wompi. Frontend y API separados para crecer a una app móvil.

**Stack:** React 18 · Vite · Tailwind · Node.js · Express · Prisma · PostgreSQL
**[Ver en vivo](https://www.sebmay.com.co/)** · **[Caso de estudio](https://github.com/EdinsonR7/sebmay-case-study)**

#### MediBook · Citas médicas en tres sedes
Base de datos de 9 tablas con triggers e índices, JWT con refresh tokens y tres roles (admin, asistente y paciente). Cumple CIE-10 y la Ley de Habeas Data.

**Stack:** React · Node.js · Express · PostgreSQL · JWT
**[Ver demo](https://gestion-citas-medicas-hazel.vercel.app/)** · **[Caso de estudio](https://github.com/EdinsonR7/medibook-case-study)**

#### Inventario-App · Gestión de inventario para comercio local
Carga de productos, búsqueda, reportes y gestión de proveedores.

**Stack:** React · Node.js · Express · PostgreSQL
